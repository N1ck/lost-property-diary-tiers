# Perdu Diary Icons

A RuneLite plugin for Old School RuneScape.

Perdu's Lost Property shop, where you reclaim achievement diary rewards, always shows
the icon for the lowest (easy) tier of each reward, regardless of how much of that diary
you've actually completed.

This plugin updates those icons to match your progress, showing the reward for the
highest diary tier you've completed. For example, if you've finished the Karamja Elite
diary, the shop shows *Karamja gloves 4* instead of the basic gloves.

It only changes how the rewards are displayed; the item you reclaim is unchanged.
